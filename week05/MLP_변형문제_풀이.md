# MLP 문제 풀이

## 1. 주어진 조건

-   직선 화살표의 가중치: -1
-   우하향 화살표의 가중치: +1
-   우상향 화살표의 가중치: +1
-   y1의 bias: +1.5
-   y2의 bias: -0.5
-   y의 bias: +0.5


## 2. 각 뉴런의 식

y1 = f(-x1 + x2 + 1.5)

y2 = f(x1 - x2 - 0.5)

y = f(y1 + y2 + 0.5)

## 3. 입력별 계산

### 1) x1 = 0, x2 = 0

y1 = f(-0 + 0 + 1.5)\
= f(1.5)\
= 1

y2 = f(0 - 0 - 0.5)\
= f(-0.5)\
= 0

y = f(1 + 0 + 0.5)\
= f(1.5)\
= 1

결과: y1 = 1, y2 = 0, y = 1

------------------------------------------------------------------------

### 2) x1 = 1, x2 = 0

y1 = f(-1 + 0 + 1.5)\
= f(0.5)\
= 1

y2 = f(1 - 0 - 0.5)\
= f(0.5)\
= 1

y = f(1 + 1 + 0.5)\
= f(2.5)\
= 1

결과: y1 = 1, y2 = 1, y = 1

------------------------------------------------------------------------

### 3) x1 = 0, x2 = 1

y1 = f(-0 + 1 + 1.5)\
= f(2.5)\
= 1

y2 = f(0 - 1 - 0.5)\
= f(-1.5)\
= 0

y = f(1 + 0 + 0.5)\
= f(1.5)\
= 1

결과: y1 = 1, y2 = 0, y = 1

------------------------------------------------------------------------

### 4) x1 = 1, x2 = 1

y1 = f(-1 + 1 + 1.5)\
= f(1.5)\
= 1

y2 = f(1 - 1 - 0.5)\
= f(-0.5)\
= 0

y = f(1 + 0 + 0.5)\
= f(1.5)\
= 1

결과: y1 = 1, y2 = 0, y = 1
