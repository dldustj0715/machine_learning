# 퍼셉트론 191p 4번 풀이

## 1. 조건

-   입력: x1 = 0, x2 = 0
-   x1의 가중치: +1
-   x2의 가중치: +1
-   bias 입력값: b = 1
-   bias의 가중치: -1.5


## 2. bias가 -1.5일 때

z = (x1 × w1) + (x2 × w2) + (b × wb)


z = (0 × 1) + (0 × 1) + (1 × -1.5)\
= 0 + 0 - 1.5\
= -1.5


답: y = 0

------------------------------------------------------------------------

## 3. bias를 -0.5로 변경한 경우

z = (x1 × w1) + (x2 × w2) + (b × wb)


z = (0 × 1) + (0 × 1) + (1 × -0.5)\
= 0 + 0 - 0.5\
= -0.5



답: y = 0
